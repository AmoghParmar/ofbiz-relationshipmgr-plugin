# OFBiz RelationshipMgr Plugin

An Apache OFBiz plugin for managing relationships between parties (persons and organizations), along with the **SoleKraft Slippers Catalog** data.

## Structure

- `relationshipmgr/` — The OFBiz plugin
- `data/` — Contains `SlippersCatalog.xml` (SoleKraft footwear catalog)

## Plugin Features

- Party management (Persons & Organizations)
- Role assignment
- Contact mechanism management (Email, Phone, Postal Address)
- SoleKraft footwear catalog with categories, products, variants, and promotions
